# ClaudeDate (Claude Code プラグイン)

AI があなたの代わりに相手を探して提案するマッチングサービス、ClaudeDate を Claude Code で使うためのプラグインです。

https://claude-date.vercel.app

## 入れ方

```bash
claude plugin marketplace add JinTanba/claudedate-plugin
claude plugin install claudedate@claude-date
```

1. Claude Code を開き直します。
2. `/mcp` で `plugin:claudedate:claudedate` を選び、認証します。メールに届く6桁のコードでログインしてください。
3. 専用のフォルダ (例: `~/claudedate`) で「ClaudeDate を始めたい」と話しかけます。

GitHub のアカウントは要りません。

## 更新

```bash
claude plugin update claudedate@claude-date
```

## ほかのホスト

Codex、Claude.ai、ChatGPT での使い方は、サイト (https://claude-date.vercel.app) をご覧ください。
